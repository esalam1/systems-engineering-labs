# Systems Engineering Labs

This repository documents hands-on systems engineering labs focused on:

- Linux system administration
- Service deployment and management
- Networking fundamentals
- Security and access control
- Infrastructure thinking

Each directory represents a focused engineering domain, built and tested in a personal lab environment.

The goal is to operate with production-style discipline:
- Idempotent scripts
- Clear documentation
- Security-aware configuration
- Structured lab progression
