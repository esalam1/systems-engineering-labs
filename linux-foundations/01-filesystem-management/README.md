# Module 1 – Filesystem Management

## Objective
Safely create, organize, and back up files in a structured workspace.

## Engineering Focus
- Absolute vs relative paths
- Structured project directories
- Backup strategies before modification
- Documentation and comments

## Risks Identified
- Overwriting configuration files
- Misreferencing paths in scripts
- Poor directory structure impacting automation

## Production Relevance
- Prevents accidental downtime in scripts and services
- Ensures repeatability and clarity in automation pipelines
- Foundation for cloud VM and container setups
